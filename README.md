# نظام حصر ومتابعة غياب الطالبات — المتوسطة الثانية لتحفيظ القرآن

نسخة مطابقة لنظام المتوسطة التاسعة والستون، بنفس التصميم والوظائف، بثلاث اختلافات فقط:
اسم المدرسة، بيانات الطالبات (٣ صفوف، فصلين لكل صف عدا الثالث المتوسط فله فصلان أيضًا)، ولون الهوية (أزرق بدل الأخضر) لتمييزها بسرعة عن لوحة المدرسة الأولى.

## الملفات
- `index.html` — صفحة تسجيل الغياب العامة.
- `dashboard.html` — لوحة المتابعة الخاصة بالموجهة الطلابية.
- `style.css` — نفس التصميم، بنسخة الألوان الزرقاء.
- `students-data.js` — بيانات الطالبات الـ ١٢٧ موزعة على الصفوف والفصول (مستخرجة من ملف Excel/PDF التوزيع الذي أرسلتِه).
- `moe-logo.png` — شعار الوزارة (نفس الملف).
- `apps-script.gs` — كود الخادم، يُلصق في Google Apps Script.

⚠️ **لا يوجد بانر (`banner.jpg`) في هذه النسخة** — بانر "العودة للمدارس" الذي صممتِه للمدرسة الأولى مكتوب عليه اسمها داخل الصورة نفسها، فما ينفع لهذي المدرسة. الصفحة ستعمل بشكل طبيعي بدونه (تظهر رسالة توضيحية مكانه بدل الصورة). إذا حبيتِ تضيفين بانر لاحقًا، فقط ارفعي صورة باسم `banner.jpg` بنفس المجلد.

## الإعداد من الصفر (بما إنه حساب وربستوري جديد)

بما إنك سويتِ حساب Google/GitHub جديد لهذي المدرسة، هذي كل الخطوات اللي تحتاجينها بالترتيب:

### ١. إنشاء جدول بيانات Google Sheets
افتحي [sheets.google.com](https://sheets.google.com) بحساب المدرسة الجديد، وأنشئي جدولاً جديدًا باسم مثل "بيانات غياب الطالبات - الثانية لتحفيظ القرآن".

### ٢. إضافة كود Apps Script
من داخل الجدول: الإضافات (Extensions) ← Apps Script. احذفي أي كود موجود، وألصقي محتوى `apps-script.gs` كاملاً كما هو (رمز الدخول والبريد معبّأين مسبقًا بداخله، لا حاجة لتعديلهما إلا إذا رغبتِ بتغييرهما).

### ٣. نشر الكود كتطبيق ويب
Deploy ← New deployment ← النوع "Web app":
- Execute as: **Me**
- Who has access: **Anyone**

اضغطي Deploy، وافقي على الأذونات المطلوبة (Authorize access) بحساب Google الجديد. بعد النشر، انسخي الرابط الذي يظهر (ينتهي بـ `/exec`).

### ٤. ربط الرابط بالصفحتين
افتحي `index.html` و `dashboard.html`، وفي كل منهما استبدلي:
```js
const APPS_SCRIPT_URL = "PASTE_YOUR_NEW_APPS_SCRIPT_WEB_APP_URL_HERE";
```
بالرابط الذي نسختيه.

### ٥. رفع الملفات على GitHub Pages
1. المستودع جاهز عندك: `secondtqschool/secondtqschool`.
2. ارفعي هذي الملفات لجذر المستودع: `index.html`، `dashboard.html`، `style.css`، `students-data.js`، `moe-logo.png` (و`banner.jpg` لاحقًا إذا صممتِ واحد).
3. من إعدادات المستودع: Settings ← Pages ← فعّلي النشر من الفرع الرئيسي (main) والمجلد الجذر (root).
4. بعد دقيقة أو دقيقتين، الموقع يصير متاح على:
   - تسجيل الغياب: `https://secondtqschool.github.io/secondtqschool/`
   - لوحة المتابعة: `https://secondtqschool.github.io/secondtqschool/dashboard.html`

### ٦. رمز الدخول للوحة المتابعة
`hayat2ndtqschool` (معبّأ مسبقًا داخل `apps-script.gs`، غيّريه هناك إذا حبيتِ رمزًا مختلفًا، مع ملاحظة إعادة النشر بعدها).

## بعد كل تعديل على apps-script.gs
لازم تسوين: Deploy ← Manage deployments ← تعديل (القلم) ← Version: **New version** ← Deploy. تعديل الكود وحفظه وحده لا يكفي.
