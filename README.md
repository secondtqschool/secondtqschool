# نظام حصر ومتابعة غياب الطالبات — المتوسطة الثانية لتحفيظ القرآن

نسخة مطابقة لنظام المتوسطة التاسعة والستون، بنفس التصميم والوظائف، بثلاث اختلافات فقط:
اسم المدرسة، بيانات الطالبات (٣ صفوف، فصلين لكل صف عدا الثالث المتوسط فله فصلان أيضًا)، ولون الهوية (أزرق بدل الأخضر) لتمييزها بسرعة عن لوحة المدرسة الأولى.

## الملفات
- `index.html` — صفحة تسجيل الغياب العامة.
- `dashboard.html` — لوحة المتابعة الخاصة بالموجهة الطلابية.
- `style.css` — نفس التصميم، بنسخة الألوان الزرقاء.
- `students-data.js` — بيانات الطالبات الـ ١٢٧ موزعة على الصفوف والفصول (مستخرجة من ملف Excel/PDF التوزيع الذي أرسلتِه).
- `moe-logo.png` — شعار الوزارة (نفس الملف).
- `apps-script.gs` — كود الخادم، يُلصق في Google Apps Script.


   - تسجيل الغياب: `https://secondtqschool.github.io/secondtqschool/`
   - لوحة المتابعة: `https://secondtqschool.github.io/secondtqschool/dashboard.html`
